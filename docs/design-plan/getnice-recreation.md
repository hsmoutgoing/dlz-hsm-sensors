# GetNice 网站 1:1 复刻方案

## 目标与范围

以 [getnice.com](https://getnice.com/) 为参考，尽可能 1:1 复刻其页面结构、版式、颜色、字号层级和交互，再将内容替换为 HSM Sensors 自己的产品数据、图片、Logo、公司信息和联系方式。整体视觉应当尽可能接近参考站的模板。

保留现有产品数据、技术参数、路由、多语言内容和询价流程。参考站的图片、Logo、客户背书和商业声明不直接搬用，也不编造 HSM 尚未提供的内容。

工作按阶段进行，每个阶段完成后检查效果，再进入下一阶段，避免一步改到最终版。

## P0：复刻顶部和首页首屏

先完成最直观的第一屏，用于确认还原方向。

参考站结构：

1. 顶部蓝色通栏，居中展示提示信息。
2. 黑色导航栏：左侧 Logo、中间导航、右侧主要行动按钮。
3. 全宽深色首屏：左侧大标题、说明和两个按钮；右侧大幅图片。
4. 首屏底部提供轮播位置指示和暂停控制。
5. 下方白底信任栏，横向排列证明信息。

HSM 内容替换：

- 使用 HSM Logo、导航、产品介绍和询价入口。
- 右侧使用现有传感器图片，依据素材调整图片裁切和比例。
- 轮播展示现有产品或产品类别，内容以现有资料为准。
- 信任栏使用已有的工厂直供、定制等真实信息，不使用参考站运动队 Logo 或虚构客户背书。

**验收重点：**桌面与手机首屏的布局、间距、配色、导航和轮播行为是否足够接近参考站。

## P1：复刻首页中部主体

按照参考站的大幅左右分栏交替排列、深色卡片及浅色信息区，组织现有内容：

- 第一组大图左、文字右：展示重点传感器系列。
- 第二组文字左、图片右：展示另一重点系列。
- 深色卡片区：用现有行业应用或产品分类替换参考站的使用场景。
- 浅色信息区：展示现有定制能力、工厂能力和产品选型入口。

重点还原区块顺序、背景色、图文比例、卡片数量和排版，不改变产品参数与数据来源。

## P2：复刻首页底部和页脚

参考站下半部分依次包含双列内容卡、大幅图文横幅、三列文章卡、双列产品卡和黑色多栏页脚。对应替换为：

- 使用现有公司能力、应用或资源内容填充内容卡。
- 使用现有资源页内容填充文章区域；没有对应内容的位置不编造文章。
- 使用现有产品图片和型号填充产品推荐区。
- 按参考站黑色多栏结构重排页脚，保留 HSM 的联系方式和现有链接。

## P3：复刻内页与交互

首页确认后，逐页查看并对照参考站的对应页面，处理产品列表、产品详情、公司介绍和联系入口。根据实际页面判断哪些结构可以对应复刻。

参考站包含购物和租赁流程；HSM 是工业产品询价网站，相关交互应映射到现有产品浏览和询价流程，保留现有功能。

## P4：逐项校对

在桌面和手机尺寸对照检查：

- 页面宽度、区块高度和间距。
- 图片裁切、文字换行与字号层级。
- 按钮、菜单、轮播及链接行为。
- 多语言内容、移动端布局和现有询价功能。

## 素材与还原边界

版式和交互尽可能逐项对齐；由于 HSM 自有图片的构图、文案长度和内容数量与参考站不同，替换后无法保证每个像素完全相同。实施时应将差异控制在内容和素材替换带来的范围内，不自行转向另一套设计。

参考站截图与分析基于当前可访问页面；实施各阶段时应再次核对对应页面和实际响应式表现。
